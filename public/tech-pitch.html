Frontend Framework
Technology What it is & Why we used it
Next.js 16 Framework

React meta-framework with App Router, Server Components, and built-in API routes — all in one project.

Eliminated the need for a separate backend server. API routes handle all AI calls server-side, keeping the NVIDIA API key private. File-based routing gave us 5 feature pages in minutes.
React 19 UI Library

The industry-standard declarative UI library with concurrent features and Server Components support.

React 19's async transitions make streaming AI responses feel native. Massive ecosystem = faster development with pre-built patterns and community support.
TypeScript 5 Language

Typed superset of JavaScript providing static type checking at build time.

Catches bugs before runtime — critical in a hackathon where speed matters. AI response schemas are fully typed so we always know the shape of data from NVIDIA NIM.
Tailwind CSS v4 Styling

Utility-first CSS framework. v4 uses a pure CSS engine — no config file, blazing-fast HMR.

Design tokens (teal brand, risk colours) defined once in CSS variables and consumed everywhere. Zero context-switching between HTML and CSS files during rapid development.
shadcn/ui 4 Component Lib

Copy-paste, fully-owned UI components built on Radix UI primitives. Source lives in your repo — not a dependency.

Gave us accessible, unstyled-by-default components (Dialog, Badge, Button, Accordion) that we fully customised to our teal design system. No fighting a third-party design opinion.
lucide-react 1.45 Icons

A clean, consistent open-source icon set with 1500+ icons as React SVG components.

Pixel-perfect icons for risk badges, navigation, and module cards. Tree-shaken so only used icons are bundled. Consistent 24px grid matches our design system perfectly.

AI & Language Models
NVIDIA NIM API Inference Platform

NVIDIA's enterprise-grade AI inference microservices — fully OpenAI-API-compatible cloud endpoints with ultra-low latency and GPU acceleration.

The hackathon's core requirement. NIM provides GPU-accelerated inference for a 70B model without managing any infrastructure. OpenAI-compatible API meant we used the standard SDK with a single base URL swap.
Llama 3.3 70B LLM

Meta's 70-billion parameter instruction-following model — best-in-class open model for reasoning and long-context tasks.

Legal document analysis requires deep comprehension, nuanced risk assessment, and structured JSON output. Llama 3.3 70B outperforms smaller models dramatically on this domain, consistently producing coherent, legally-aware analysis across all 5 modules.
OpenAI SDK v7 API Client

The official OpenAI TypeScript/Node.js client with support for streaming, structured outputs, and all chat completion parameters.

NVIDIA NIM exposes an OpenAI-compatible API, so we get a well-typed, battle-tested SDK for free. Streaming support means users see AI output token-by-token instead of waiting 30+ seconds for a full response.

Database & ORM
Prisma ORM 5 ORM

Next-gen Node.js & TypeScript ORM with auto-generated fully-typed client, schema migrations, and an intuitive query API.

Session management and analysis history required structured data. Schema-first approach lets us define the data model once and get a fully-typed client instantly — no raw SQL, no runtime errors from column name typos.
SQLite Database

A serverless, self-contained, zero-configuration SQL database stored as a single local file.

Perfect for a hackathon — zero infrastructure, zero cost, zero setup. Documents are never sent to an external database, making our privacy story bulletproof. One file (dev.db) holds everything and is trivially gitignored.
📄
File Processing
pdf-parse 2.4 PDF

Node.js library that extracts plain text from PDF files using Mozilla's pdf.js under the hood.

Legal documents are predominantly PDFs. Handles text layers, multi-page documents, and complex layouts — extracting clean text fed directly to the LLM without formatting noise or binary garbage.
mammoth 1.12 DOCX

Converts .docx Word documents to clean plain text or HTML, preserving semantic structure while stripping formatting noise.

Many legal contracts arrive as Word documents. Mammoth's clean extraction (vs. raw XML parsing) gives the LLM well-structured input — no XML tags or binary data polluting the context window.
multer 2.3 Upload

Node.js middleware for handling multipart/form-data — the format used for file uploads in web forms.

Handles the entire upload pipeline inside Next.js API routes: receiving the binary stream, validating MIME types, enforcing file size limits, and passing the buffer to pdf-parse or mammoth for extraction.

Typography & Design System
Geist Font Headings

Vercel's modern geometric sans-serif typeface, purpose-built for developer tools and professional UIs.

Headings and brand text use Geist for its clean, authoritative feel — appropriate for a legal tech tool where trust is paramount. Geometric forms feel precise and modern without being cold.
Inter Font Body

The gold-standard open-source typeface optimised for screen readability — used by Figma, Linear, and hundreds of leading SaaS products.

Legal documents mean dense text. Inter's optical size adjustments keep long paragraphs of AI-generated analysis highly readable at 14–16px on all screen sizes and densities.
Calm Clarity Palette Color System

Custom design system: Slate/charcoal base with teal (#0E9384) accent, warm linen background (#FAFAF9), and a semantic risk-colour scale.

Teal conveys calm authority — essential for a legal tool users trust with serious problems. The risk palette (critical red / warning amber / safe green) maps directly to legal clause severity, making complex analysis scannable at a glance.

Dev Tooling
ESLint 9 Linter

Industry-standard JavaScript/TypeScript linter with flat config support introduced in v9.

Next.js ships with eslint-config-next that catches React mistakes (missing keys, invalid hooks) automatically. Flat config makes domain-specific rules easy to add without complex setup overhead.
class-variance-authority Utility

A tiny utility for building variant-based component APIs with Tailwind CSS classes.

Powers our RiskBadge component — one component handles critical, warning, and safe variants with different colours and styles. No conditional string concatenation spaghetti.
tailwind-merge Utility

Intelligently merges Tailwind CSS classes, resolving conflicts (e.g. p-2 + p-4 → p-4) without duplicates.

Essential for the cn() utility used throughout shadcn/ui — ensures dynamic class overrides work correctly when components accept className props from parent pages.
